The first thing you see when starting your laptop or smart phone is the operating system, either it's **ios** or **windows**, etc.
The `Operating System` is a software that start your device. and store your files, apps, and more.
The `Operating System` is software that manages the **computer hardware**, and provide environment so the user can interact with.
each `Operating System` have their own graphical interface and command line.
without `Operating System` it will be diffuclt to use the computer.

## Concept

`Operating System` is a software that gives the user an environment to interact with the computer hardware commponets (CPU, RAM, I/O), Files storing and provide `graphical interface`, `command line` to make the user intraction easy, most of the Operatig System provide common software (Text editor, Media player, and more). `Operating System`is also resonable of running the software.
